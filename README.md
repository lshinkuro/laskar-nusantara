# Laskar Nusantara

Roguelite arena shooter bertema Nusantara (Godot 4.7, renderer Compatibility). Rencana lengkap: [PLAN.md](PLAN.md).

**Kontrol:** WASD / panah untuk bergerak (HP: sentuh & geser di mana saja). Senjata menembak otomatis. Enter / klik / tap untuk lanjut wave.

## Jalankan lokal
Buka folder ini di Godot 4.7 → F5.

## Rilis web
Setiap push ke `main` otomatis di-export ke Web dan di-deploy ke GitHub Pages
(`.github/workflows/deploy.yml`). Thread Support dimatikan, jadi tidak perlu header COOP/COEP.
Sekali saja: Settings → Pages → Source: **GitHub Actions**.
